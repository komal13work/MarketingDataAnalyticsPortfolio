# MarketingDataAnalyticsPortfolio
Marketing Management portfolio focused on data-driven SME (Small and Medium-sized Enterprises) growth. features a commercial optimization study for Coco Bliss. Using Excel, SQL Server, Python (Pandas/Seaborn), and Power BI, I audited A 15+ SKU (Stock Keeping Unit) product mix to eliminate margin leakages and maximize weekly net profitability.
